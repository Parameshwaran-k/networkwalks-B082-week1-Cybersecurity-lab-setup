# networkwalks-B082-week1-Cybersecurity-lab-setup
Cybersecurity Lab setup

Step 1:

Download & Install 7-Zip
Downloaded and installed 7-Zip on my system.
Learned about compressed file formats such as .zip and .7z.
Learned how to extract compressed files and access the files inside them.
Used 7-Zip to handle the files required for the virtual machine setup.
Understood that file compression makes it easier to store and transfer large files.

Step 2:

Download & Install VirtualBox
Downloaded and installed Oracle VirtualBox.
Learned the basic concept of virtualization.
Understood that a virtual machine allows another operating system to run inside the main operating system.
Learned about important VM settings such as RAM, storage, CPU, and network adapters.
Created and configured a virtual machine environment for cybersecurity practice.
Understood that using a virtual machine provides an isolated environment for learning and testing.

Step 3:

Configure NAT Network
Created a NAT Network in VirtualBox.
Configured the network using the 10.0.0.0/24 network range.
Learned the basic concept of IP addresses and subnet ranges.
Understood how virtual machines can communicate with each other through a virtual network.
Learned the difference between the normal NAT option and a NAT Network.
Configured the network settings required for the cybersecurity lab.
This helped me understand the practical side of basic networking.

Step 4:

Download & Import Kali Linux
Downloaded the Kali Linux virtual machine.
Imported the Kali Linux VM into VirtualBox.
Configured the required hardware settings for the VM.
Started Kali Linux successfully inside VirtualBox.
Learned about Kali Linux and its role in cybersecurity and ethical hacking.
Understood why Kali Linux is commonly used for security testing and learning.
Learned how an operating system can be safely used inside a virtual environment.

Step 5:

Configure IP Settings in Kali Linux
Configured the network settings inside Kali Linux.
Learned how to check and configure an IP address.
Understood the relationship between the IP address, network, and gateway.
Practiced basic network configuration in Linux.
Learned how to verify whether the system is connected to the configured network.
Improved my understanding of networking through practical configuration.
Connected the Kali Linux environment to the virtual lab network.

Step 6:

Take a Snapshot of the VM
Created a snapshot of the Kali Linux virtual machine after completing the setup.
Learned what a virtual machine snapshot is.
Understood that a snapshot can save the current state of a VM.
Learned that snapshots can be useful before making major configuration changes.
Understood how a previous working state can be restored if something goes wrong.
This gave me a safer way to experiment with the cybersecurity lab.
